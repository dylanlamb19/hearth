# Hearth

Warm quieter social for people you already know.

## Run locally

Install dependencies, then start the Next.js app:

    cd hearth
    npm install
    npm run dev

Open http://localhost:3000

## Build

    npm run build
    npm start

## Demo login

Use any email after signup, or the seeded Ember account shown on the login page.

## Routes

Public: /, /login, /signup, /forgot-password, /about, /help, /terms, /privacy, /pricing

App: /home, /moments, /friends, /messages, /groups, /events, /marketplace, /videos, /notifications, /saved, /profile

## Notes
